## 主な発見

### changelog 記述の反証

- **hook `if: "Bash(...)"` のマッチ挙動**: changelog は「`$()`/`$VAR` を含む全 Bash にマッチ」と読める文言だったが、実測では **shell 構文解析でサブコマンド名 glob 判定** をしている。`echo $(git status)` は `Bash(git *)` に発火するが、`echo $(date)` は発火しない。7 ケースマトリクスで確定。

### 新発見フィールド・挙動

- **CLI vs 対話 UI の別物**: `claude plugin list` に `--enabled/--disabled` オプションは存在しない。フィルタは対話 UI の `/plugin list` のみ。headless では `/plugin isn't available in this environment.` が返る。
- **`claude plugin init` の配置先**: CHANGELOG の `.claude/skills` は誤記ではなく正しい。`claude plugin init` は `$CLAUDE_CONFIG_DIR/skills/` に作成し、`<name>@skills-dir` として自動ロードされる。`plugins/` は cache 置き場。
- **`MessageDisplay` の固有 stdin フィールド**: `delta` / `final` / `index` / `message_id` / `turn_id` を新規発見。他 hook にはない固有フィールド。
- **Stop/SubagentStop の `additionalContext`**: hook error 扱いにせず会話継続のまま注入できることを実証。固有トークン復唱方式で確認。
- **SessionStart `reloadSkills:true`**: hook が動的に設置した skill が同一 session で使えることを実証。
- **`\$` エスケープ**: `\$1` → リテラル `$1`、`\\$1` はエスケープ不成立。引数の有無に非依存。9 ケースマトリクスで確定。
- **`disallowed-tools`**: deny メッセージで拒否を実証。対照群 (許可版) との比較で確認。

### メイン監査での格下げ修正

サブエージェントは changelog / docs 由来の記述に `[実機検証済]` を付けがち。監査で以下を是正:

- 未観測の `waitingFor` 値例
- `--all` オプション (agents)
- `defaultEnabled` (docs 由来)
- `--safe-mode` の無効化範囲
- SubagentStop が blockable かどうか

これらを `[未検証]` または `[spec]` に格下げ。
